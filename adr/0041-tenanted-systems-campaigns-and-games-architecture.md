# 0041: Tenanted Systems, Campaigns, and Games Two-Level CTI and Domain Decomposition Architecture

- Status: accepted, amends ADR-0005, ADR-0032, ADR-0035
- Date: 2026-11-13

## Context

In **Njall**, tenanted resources in the **User plane** use a Common Table Inheritance (CTI) hierarchy rooted at `njall_users.entities`, governed by [0005: Sealed DAO and Hibernate Dual Session Architecture](0005-sealed-dao-and-hibernate-dual-session-architecture.md), [0011: ArchUnit Injected Constructor Visibility and Package Dependency Rules](0011-archunit-injected-constructor-visibility-and-package-dependency-rules.md), [0025: User Space Studios API and Tenant Row-Level Security](0025-user-space-studios-api-and-tenant-row-level-security.md), [0027: Common Table Inheritance and Tenanted Links Architecture](0027-common-table-inheritance-and-tenanted-links-architecture.md), [0030: DAO Naming Conventions and Entity Immutability Standards](0030-dao-naming-conventions-and-entity-immutability-standards.md), [0032: Package Size Limits and Subpackage Decomposition](0032-package-size-limits-and-subpackage-decomposition.md), [0033: Federated Hashtags and Case-Insensitive Functional Indexing](0033-federated-hashtags-and-case-insensitive-functional-indexing.md), [0035: Tenanted Events and Location Associations Architecture](0035-tenanted-events-and-location-associations-architecture.md), [0037: Tenanted Collections Architecture](0037-tenanted-collections-architecture.md), [0038: Tenanted Actors and Federated Endpoints Architecture](0038-tenanted-actors-and-federated-endpoints-architecture.md), and [0040: Actor-Parented Collections Routes and Entity Generator Column](0040-actor-parented-collections-and-entity-generator-column.md).

Expanding **Studio** scheduling to support roleplaying rulesets (**System**, implemented in Java with the **GameSystem** prefix to avoid colliding with `java.lang.System`), multi-session chronicles (**Campaigns**), and runnable game sessions (**Games**) introduces four architectural decisions that extend or amend prior ADRs:
1. **Two-Level Event Specialization**: Every **Games** **Entity** has `1:1` structural parity with an **Events** **Entity** (`title`, `summary`, `location_id`, `start_time`, `end_time`) plus a required **System** and an optional **Campaigns** reference independent of `campaign.system`, while non-game **Events** require an `event_type` classification (`EVENT_TYPE_UNSPECIFIED`, `WORKSHOP`, `CONFERENCE`, `MEETUP`).
2. **Resource Pathing and Single-URI Discipline**: **Games** have a many-to-one relationship to **System** and an optional many-to-one relationship to **Campaigns**, requiring flat AIP-124 peer collections with canonical AIP-122 resource URIs and strictly disjoint `/v1/events` vs `/v1/games` collections.
3. **Domain Package Capacity vs Unnamed-Module `sealed` Interfaces**: `com.larpconnect.njall.data.domain` reached the 20-type ceiling enforced by [ADR-0032](0032-package-size-limits-and-subpackage-decomposition.md), and in Java's unnamed module `sealed interface DatabaseObject` ([ADR-0005](0005-sealed-dao-and-hibernate-dual-session-architecture.md)) cannot permit domain records across subpackages.
4. **Route Aggregation and Upward-Dependency Limits**: Adding three new studio route classes would push `StudioSubRoutes` past Checkstyle's 8-parameter limit ([ADR-0030](0030-dao-naming-conventions-and-entity-immutability-standards.md)), and `DefaultGameDAO` requires access to `EventEntity` without depending upward on `com.larpconnect.njall.data.dao.studios` ([ADR-0011](0011-archunit-injected-constructor-visibility-and-package-dependency-rules.md)).

## Considered Options

- **Option 1: Two-Level CTI (`games` -> `events` -> `entities`), Disjoint Flat AIP-124 Peer Collections, Unsealed `DatabaseObject` Across `data.domain.*` Subpackages, and `@StudioSubRoute` Multibinding** (Selected)
- **Option 2: Nullable `system_id` and `campaign_id` Columns Directly on `njall_users.events` Shared Under `/v1/events`** (Rejected: pollutes non-game events with game-only foreign keys, prevents table-level `NOT NULL` enforcement on `games.system_id`, and creates dual/ambiguous resource contracts).
- **Option 3: Hierarchical Sub-Collections (`/campaigns/{id}/games` or `/systems/{id}/games`) and JPMS `module-info.java` to Retain `sealed DatabaseObject`** (Rejected: breaks canonical **FeatherPub** URIs for standalone or reassigned games and adds disproportionate JPMS split-package friction across all Gradle modules).

## Decision

1. **Two-Level CTI Schema and Event Classification (`V14__systems_campaigns_and_games.sql`)** (amends [ADR-0035](0035-tenanted-events-and-location-associations-architecture.md)):
   - Define `njall_users.tevent_type` (`'EVENT_TYPE_UNSPECIFIED'`, `'GAME'`, `'WORKSHOP'`, `'CONFERENCE'`, `'MEETUP'`) and add `event_type njall_users.tevent_type NOT NULL DEFAULT 'EVENT_TYPE_UNSPECIFIED'` to `njall_users.events`.
   - Create `njall_users.systems` (`entity_type = 'System'`) inheriting `(tenant_id, id)` from `njall_users.entities ON DELETE CASCADE` with case-insensitive per-tenant unique index `idx_systems_tenant_name ON (tenant_id, lower(name))` mapped to `409 Conflict`.
   - Create `njall_users.campaigns` (`entity_type = 'Campaign'`) inheriting `(tenant_id, id)` from `njall_users.entities ON DELETE CASCADE` with optional `(tenant_id, system_id) REFERENCES njall_users.systems(tenant_id, id) ON DELETE SET NULL` and `title VARCHAR NOT NULL`.
   - Create 2nd-level CTI table `njall_users.games` (`entity_type = 'Game'`, `event_type = 'GAME'`) inheriting `(tenant_id, id)` from `njall_users.events(tenant_id, id) ON DELETE CASCADE` (`1:1` game-to-event parity) with required `(tenant_id, system_id) REFERENCES njall_users.systems(tenant_id, id)` and optional `(tenant_id, campaign_id) REFERENCES njall_users.campaigns(tenant_id, id) ON DELETE SET NULL` (independent of `campaign.system_id`), protected by Row-Level Security (`app.tenant_id`) and `njall_admin` bypass policies.
2. **Flat AIP-124 Peer Collections, Disjoint `/v1/events` vs `/v1/games`, and AIP-122 Resource URIs** (amends [ADR-0035](0035-tenanted-events-and-location-associations-architecture.md)):
   - Expose `/api/studios/{studio-id}/v1/systems`, `/v1/campaigns`, and `/v1/games` as flat studio peer collections (`POST`, `GET` list, `GET` detail, AIP-134 `PATCH`, soft-delete `DELETE`).
   - Scope `/v1/events` strictly to `entity_type = 'Event'` (rejecting `eventType = "GAME"` on `POST` and `PATCH` with `400 Bad Request`, and returning `404 Not Found` on `'Game'` IDs) and scope `/v1/games` strictly to `entity_type = 'Game'` (emitting output-only `eventType = "GAME"`).
   - Format `generator`, `system`, and `campaign` fields as canonical studio URIs (`/api/studios/{studio-id}/v1/<collection>/{id}`) via `StudioResourceUriSupport` while accepting either a bare UUID or same-studio canonical URI on input and list filters (`?systemId`, `?campaignId`).
3. **Unsealing `DatabaseObject` and Subpackage Decomposition in `:data` and `:api`** (amends [ADR-0005](0005-sealed-dao-and-hibernate-dual-session-architecture.md), [ADR-0032](0032-package-size-limits-and-subpackage-decomposition.md)):
   - Unseal `DatabaseObject` and decompose `com.larpconnect.njall.data.domain` into sibling subpackages `common` (`DatabaseObject`, `DeletionFilter`, `GeoJsonPoint`), `admin`, `servers`, and `studios` (housing `EventType`, `Event`, **GameSystem**, `Campaign`, `Game`, and existing studio domain records), leaving zero classes in ancestor `com.larpconnect.njall.data.domain`.
   - Move `EventDAO`, `DefaultEventDAO`, and `public class EventEntity` (exposed as a CTI parent entity like `EntityBaseEntity`) to `com.larpconnect.njall.data.dao.studios.events` (`EventsDaoModule`) alongside `systems` (`SystemsDaoModule`), `campaigns` (`CampaignsDaoModule`), and `games` (`GamesDaoModule`), using `@Immutable` parameter records (`CreateGameParams`, `PatchGameParams`, `PatchCampaignParams`) to satisfy the 8-parameter Checkstyle limit ([ADR-0030](0030-dao-naming-conventions-and-entity-immutability-standards.md)) and hydrating `System` and `Campaign` display names in `CollectionItemHelper.EXPANDED_ITEMS_QUERY`.
   - Introduce `@StudioSubRoute` in `com.larpconnect.njall.api.studios.common` so top-level studio subroute modules contribute `RouteProvider` bindings via Guice `Multibinder` into `StudioSubRoutes(@StudioSubRoute Set<RouteProvider>)`.

## Consequences

- **Positive**: Good, because 2-level CTI enforces `NOT NULL` system associations on **Games** while inheriting **Events** scheduling, venue foreign keys, tags, reactions, and expanded **Collections** hydration; flat AIP-124 paths and disjoint `/v1/events` vs `/v1/games` guarantee one canonical **FeatherPub** URI per entity; unsealing `DatabaseObject` across `data.domain.*` and multibinding `@StudioSubRoute` preserve strict compliance with the 20-type package cap, 8-parameter Checkstyle limit, and zero-upward-dependency ArchUnit rules.
- **Negative**: Bad, because unsealing `DatabaseObject` trades cross-package compile-time exhaustiveness over all domain records for subpackage modularity, and creating or reading a **Games** entity joins three CTI tables (`entities`, `events`, `games`) within the `@NjallUsers` transaction.
