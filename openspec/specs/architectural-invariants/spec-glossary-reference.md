# Architectural Invariants Spec Glossary Reference

The following terms from the **Njall** technical glossary are referenced in `specs/architectural-invariants/spec.md`:

| Term | Context in Specification |
| --- | --- |
| **Njall** | Application codebase and package namespace prefix `com.larpconnect.njall`. |
| **Library module** | Gradle library module `:integration` hosting ArchUnit architecture tests. |
| **Module** | Guice dependency injection modules configuring subpackages (`StudiosModule`, `DaoModule`, etc.). |
| **Actor** | Apache Pekko typed actor factory and message protocol types. |
| **DAO** | Data access object abstractions and JPA entity mappings. |
