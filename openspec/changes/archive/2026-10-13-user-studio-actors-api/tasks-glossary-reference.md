# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Actor | `glossary/business.md` | Entity capable of sending and receiving federated messages. |
| Agent | `glossary/technical.md` | Java implementation components representing Actor entities. |
| Collections | `glossary/business.md` | Entity holding references to an ordered set of other entities. |
| DAO | `glossary/technical.md` | Data access object abstracting entity persistence. |
| DTO | `glossary/technical.md` | Data transfer object representing serialized request/response payloads. |
| Verticle | `glossary/technical.md` | Slice of the application centering on a specific responsibility. |
