# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| GameSystem | `glossary/technical.md` | Java implementation prefix (`GameSystem`, `GameSystemDAO`, `GameSystemActor`) representing `System` entities. |
| Actor | `glossary/business.md` | Entity generator validated by `ActorGeneratorValidator` and Pekko Typed actor components in `:api`. |
| DTO | `glossary/technical.md` | Immutable Jackson request/response records documented in `openapi.yaml` and `:api`. |
| Collections | `glossary/business.md` | Ordered entity container whose expanded view hydrates `System`, `Campaign`, and `Game` items. |
| DAO | `glossary/technical.md` | Data access interfaces and Hibernate implementations in `:data`. |
