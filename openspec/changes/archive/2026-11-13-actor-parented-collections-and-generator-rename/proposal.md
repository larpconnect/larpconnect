## Why

Every **Collections** **Entity** in **Njall** is structurally generated by a responsible **Actor** (**generator**), yet the **User plane** HTTP API currently exposes **Collections** on an unparented path (`/api/studios/{studio-id}/v1/collections/{collection-id}`) while the **Data plane** names the root provenance column `njall_users.entities.owner`—colliding with semantic attachment (`njall_users.collections.owner_id`, **owner**). Parenting **Collections** endpoints under `/api/studios/{studio-id}/v1/actors/{actor-id}/collections` and renaming `entities.owner` to `entities.generator` aligns URL hierarchy, domain models, and database schema with **FeatherPub** provenance semantics while leaving tags, locations, events, individuals, and links unparented.

## What Changes

- **BREAKING**: Repath all tenanted **Collections** HTTP endpoints in `:api` and `openapi.yaml` under the generating **Actor** resource while keeping tags, locations, events, individuals, and links unparented:
  - `POST /api/studios/{studio-id}/v1/actors/{actor-id}/collections` (create collection; `GET` on the collection root continues returning `404 Not Found`).
  - `GET | PATCH | DELETE /api/studios/{studio-id}/v1/actors/{actor-id}/collections/{collection-id}` (retrieve compressed/expanded, partially update, soft-delete).
  - `POST /api/studios/{studio-id}/v1/actors/{actor-id}/collections/{collection-id}:addItem` and `:removeItem` (custom item mutation methods).
- **BREAKING**: Simplify `CreateCollectionRequest` on `POST /api/studios/{studio-id}/v1/actors/{actor-id}/collections`:
  - Remove `generator` from the request payload because `{actor-id}` in the URL path establishes `entities.generator` (returning `404 Not Found` if `{actor-id}` is missing, soft-deleted, or not an **Actor**).
  - Make `ownerId` optional in `CreateCollectionRequest`, defaulting semantic **owner** attachment (`collections.owner_id`) to `{actor-id}` when omitted and returning `400 Bad Request` when an explicit `ownerId` does not reference an active **Entity** in the same **Studio** **Tenant**.
- Scope all **Collections** read and mutation operations by `{actor-id}` so accessing a collection under a missing, soft-deleted, non-**Actor**, or mismatched **Actor** path returns `404 Not Found`, delegating `/collections` subroutes from `AgentRoute` to `CollectionsRoute` (removing `CollectionsRoute` from top-level `StudioSubRoutes`).
- Add Flyway migration `V13__rename_entities_owner_to_generator.sql` in `:data` renaming `njall_users.entities.owner` to `generator`, `fk_entities_owner` to `fk_entities_generator`, and `idx_entities_owner` to `idx_entities_generator` (retaining `njall_users.collections.owner_id`), and update PostgreSQL seed scripts (`docker/postgres/seed/`).
- Rename `owner` to `generator` across `:data` JPA mappings (`EntityBaseEntity`), validation (`ActorOwnerValidator` -> `ActorGeneratorValidator`), immutable domain records (`Agent`, `Collection`, `Event`, `Hashtag`, `Individual`, `Link`, `Location`, `ExpandedEntity`), and tenanted **DAO** interfaces and implementations.
