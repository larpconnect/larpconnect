# Design Glossary Reference

The following terms from the **Njall** technical glossary are referenced in `design.md`:

| Term | Context in Design |
| --- | --- |
| **Njall** | Application codebase and package namespace. |
| **Actor** | Apache Pekko typed actors handling domain logic. |
| **DAO** | Data access object layer and domain repositories. |
| **DTO** | Data transfer objects used in REST protocols. |
| **Module** | Guice dependency injection modules and Gradle modules. |
| **Library module** | Gradle library modules such as `:integration`. |
| **Server** | Core server application and daemon. |
