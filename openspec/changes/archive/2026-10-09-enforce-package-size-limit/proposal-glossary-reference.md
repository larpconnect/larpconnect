# Proposal Glossary Reference

The following terms from the **Njall** technical glossary are referenced in `proposal.md`:

| Term | Context in Proposal |
| --- | --- |
| **Njall** | Internal project name for the application codebase. |
| **Actor** | Apache Pekko typed actor managing asynchronous business workflows. |
| **DTO** | Data transfer object representing HTTP JSON payloads. |
| **DAO** | Data access object interface abstracting database interactions. |
| **Server** | Core server application and daemon hosting API routes. |
| **Library module** | Gradle library modules such as `:integration`, `:api`, and `:data`. |
