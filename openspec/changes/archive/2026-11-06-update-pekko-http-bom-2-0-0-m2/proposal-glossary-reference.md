# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Njall | `glossary/technical.md` | Internal code name of the application whose Pekko HTTP dependency BOM is being upgraded. |
| Module | `glossary/technical.md` | Gradle modules in the multimodule build affected by the Pekko HTTP BOM version update. |
| Library module | `glossary/technical.md` | Shared non-executable Gradle modules (`:api` and `:test`) consuming Pekko HTTP artifacts. |
| Application module | `glossary/technical.md` | Executable `:server` Gradle module hosting the Pekko HTTP runtime. |
| Server | `glossary/technical.md` | The HTTP runtime component that binds network sockets and serves the API. |
