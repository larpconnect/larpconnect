# Glossary Reference

| Term | Source Glossary | Context |
| --- | --- | --- |
| Studio | `glossary/business.md` | A business unit and tenant that hosts games and manages players. |
| Tenant | `glossary/business.md` | A studio when its data is segmented and isolated from other studios. |
| Server | `glossary/technical.md` | The backend application runtime hosting the API plane. |
| Data plane | `glossary/technical.md` | The data persistence subsystem, DAOs, and Hibernate session factories. |
| API plane | `glossary/technical.md` | The HTTP routing and API endpoints exposed to clients. |
